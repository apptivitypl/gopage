# C309 — match is not exhaustive

## Message

```
error[GOPAGE-C309]: match on Status does not handle StatusArchived
```

## Why this is rejected

A match has no fallthrough. An unhandled case would render nothing at all, which is the failure mode that is hardest to notice in review.

## How to fix it

Handle every constant of the type, or add the missing case. The subject must be a named type with exported constants declared in the Go block, for example `type Status string` with `const StatusActive Status = "active"`.
