# C310 — malformed element attribute

## Message

```
error[RILL-C310]: :class needs a value
```

## Why this is rejected

Attributes are compiled, not copied. A bound value becomes an expression, a conditional value becomes a jump, and a class map becomes a chain of them, so the compiler has to know which form it is looking at.

## How to fix it

The forms are `name="literal"`, `:name="expression"`, `name?="condition"` and `:class="{ 'is-active': Selected }"`. Every value is quoted.
