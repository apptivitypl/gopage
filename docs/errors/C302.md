# C302 — unsupported props type

## Message

```
error[GOPAGE-C302]: Props.Filters uses a map, which props cannot carry
```

## Why this is rejected

The props type set is closed on purpose. It is what makes accessors generatable without reflection, template paths checkable at build time, and island props serialisable. Every type admitted here would have to be handled by all three.

## How to fix it

Props carry bools, numbers, strings, slices, pointers and structs declared in the same block. Convert anything else in `Load` and pass a simple type.
