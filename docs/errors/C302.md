# C302 — unsupported props type

## Message

```
error[GOPAGE-C302]: Props.Filters uses a map, which props cannot carry
help: props carry bools, numbers, strings, times, slices, pointers, structs from this block and structs from this module's own packages; convert anything else in Load
```

## Why this is rejected

The props type set is closed on purpose. It is what makes accessors generatable without reflection, template paths checkable at build time, and island props serialisable. Every type admitted here would have to be handled by all three.

## How to fix it

Props carry bools, numbers, strings, `time.Time`, slices, pointers, structs declared in the same block, and structs from your own module's packages. Convert anything else in `Load` and pass a simple type.

A type from one of your packages is read straight from its source, so the fields stay checked:

```gopage
---
import "example.com/site/server/chrome"

type Props struct {
	Nav chrome.Nav
}
---
<a href="/">{{ Nav.Home }}</a>
```

`{{ Nav.Ghost }}` is still `GOPAGE-C305`, naming `chrome.Nav`.

## What this check does not cover

Packages outside your module, and methods on adopted types. A computed value belongs to the block that declares the props:

```go
func (p Props) Total() int { return len(p.Items) }
```
