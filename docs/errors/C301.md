# C301 — unreadable go block

## Message

```
error[GOPAGE-C301]: cannot read the Go block: expected declaration, found ...
```

## Why this is rejected

The block between the fences becomes real Go in the generated package. If it does not parse, nothing downstream can be trusted: no props schema, no accessors, no type checking of the template.

## How to fix it

The block holds imports and declarations, the same as the top of a Go file. Imports come before other declarations.
