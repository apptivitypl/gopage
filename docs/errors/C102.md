# C102 — page under the api namespace

## Message

```
error[GOPAGE-C102]: app/api/oops/page.gopage renders a page under /api
```

## Why this is rejected

`/api` never carries a locale prefix, has no hreflang, no canonical, no sitemap entry, and is skipped by differential navigation. A rendered page there would be invisible to every one of those subsystems.

## How to fix it

Move the page outside `app/api`, or replace it with a `route.go` handler if it was meant to serve data.
