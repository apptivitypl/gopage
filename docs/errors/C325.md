# C325 — malformed sitemap hook

## Message

```
error[GOPAGE-C325]: Sitemap has the wrong signature
help: write func Sitemap(ctx *gopage.Ctx) (gopage.SitemapSeq, error)
```

## Why this is rejected

`Sitemap` is a route-level hook, discovered the same way as `Load`, `Meta` and `Submit`. The
generated provider calls it with a context and streams whatever it returns straight into
`/sitemap.xml`, so the shape is fixed — nothing reflects over the function at runtime.

The hook takes no `params`. It enumerates every address the route can answer, not one of them, so a
single set of parameters would have nothing to say.

## How to fix it

Match the signature, and return a sequence:

```go
func Sitemap(ctx *gopage.Ctx) (gopage.SitemapSeq, error) {
	cities, err := catalog.Cities(ctx.Context())
	if err != nil {
		return nil, err
	}
	return func(yield func(gopage.SitemapEntry, error) bool) {
		for _, city := range cities {
			entry := gopage.SitemapEntry{Path: "/jobs/" + city.Slug, LastMod: city.Updated}
			if !yield(entry, nil) {
				return
			}
		}
	}, nil
}
```

For a short list, `gopage.SitemapOf` wraps a slice:

```go
return gopage.SitemapOf([]gopage.SitemapEntry{{Path: "/jobs/warszawa"}}), nil
```

A route that declares the hook replaces the entries the framework would have derived for it, so the
paths you yield are the ones crawlers get — including localised ones the route table does not know.

## What this check does not cover

What the sequence yields. An entry with an empty path, or one pointing at a redirect, is a bug the
compiler cannot see.
