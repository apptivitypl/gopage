# C002 — unterminated interpolation

## Message

```
error[RILL-C002]: the interpolation is never closed
```

## Why this is rejected

`{{` opens an interpolation. Leaving it open would silently swallow the rest of the template as an expression.

## How to fix it

Close it with `}}`. To print a literal `{{`, split it across two text nodes or use an HTML entity.
