# C004 — unknown directive

## Message

```
error[RILL-C004]: unknown directive "fragment"
```

## Why this is rejected

Directives are a closed set. An unrecognised name is either a typo or a feature that does not exist yet, and guessing at intent would produce a page that silently drops content.

## How to fix it

Check the spelling against the directives this version supports. The compiler suggests the closest match when there is one.
