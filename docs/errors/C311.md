# C311 — malformed built-in component

## Message

```
error[RILL-C311]: a field needs a literal name attribute
help: write <Field name="Email" /> naming the form field it edits
```

## Why this is rejected

`<Field>` compiles to markup at build time: the `id`, the `for` of its label, the `name` of the
input and the two lookups into `form.Values` and `form.Errors` all come from one literal string.
A name computed at request time would leave the compiler with nothing to write, and the field
would silently stop round-tripping its value after a rejected submission.

## How to fix it

Give the field a literal name matching the field on the form struct:

```rill
<Field name="Email" label="your email" type="email" />
```

For a repeated group of inputs, write the `<input>` elements directly and read `form.Values`
yourself.
