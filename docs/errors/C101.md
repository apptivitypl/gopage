# C101 — conflicting routes

## Message

```
error[GOPAGE-C101]: app/thing/page.gopage and app/thing/route.go both answer /thing
```

## Why this is rejected

Two files claiming one URL make the served response depend on discovery order. The build refuses rather than picking one.

## How to fix it

A segment holds either a page or a route handler. Route groups that collapse to the same path collide the same way; rename one of them.
