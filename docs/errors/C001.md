# C001 — unterminated frontmatter fence

## Message

```
error[RILL-C001]: the frontmatter fence is never closed
```

## Why this is rejected

A file that opens with `---` promises a Go block. Without the closing fence the compiler cannot tell where your code ends and the template begins, so every later diagnostic would point at the wrong place.

## How to fix it

Close the block with a line containing only `---`. If the file was never meant to carry Go code, remove the opening fence; a `---` anywhere below the first line is ordinary text.
