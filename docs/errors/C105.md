# C105 — malformed route handler

## Message

```
error[GOPAGE-C105]: GET has the wrong signature
help: write func GET(ctx *gopage.Ctx, params gopage.Params) (gopage.Response, error)
```

## Why this is rejected

The generated adapter calls the handler directly, without reflection. The signature is therefore fixed: the request context and the path parameters in, a response and an error out. A different shape cannot be wired, and the failure would otherwise surface as a compile error inside generated code rather than against the file the author wrote.

The same code reports a `route.go` that does not parse as Go.

## How to fix it

Match the signature exactly:

```go
func POST(ctx *gopage.Ctx, params gopage.Params) (gopage.Response, error) {
	return gopage.NoContent(), nil
}
```

Query strings and request bodies are read through `ctx`, not through extra parameters.
