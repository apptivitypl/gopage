# C326 — interpolation in a literal attribute

## Message

```
error[GOPAGE-C326]: Action is passed on literally, interpolation included
help: bind the expression instead: :Action="…"
```

## Why this is rejected

A component prop written as `Prop="{{ Expr }}"` is not interpolated. The value reaches the component
as the seven characters `{{ Expr }}`, and the page renders them verbatim — a form ends up posting to
`%7B%7B%20Expr%20%7D%7D`, an image asks the CDN for a file with braces in its name.

Nothing about that is visible until you read the rendered HTML, which is why the compiler now refuses
it rather than passing it through.

## How to fix it

Bind the expression with a colon:

```gopage
<SearchBar :Action="NavJobs" />
<Image :Src="item.Photo" :Alt="item.Name" Width="800" Height="600" />
```

A literal value stays a literal value, with no colon and no braces:

```gopage
<SearchBar Action="/jobs" />
```

## What this check does not cover

Ordinary element attributes. `<a href="/items/{{ id }}">` is interpolated as written — the rule is
about attributes read as literals: component props and the built-in components.
