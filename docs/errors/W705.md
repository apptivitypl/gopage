# W705 — standalone layout without a head

## Message

```
warning[GOPAGE-W705]: a standalone layout carries no {% assets %}
help: a layout that starts its own chain answers for the head; add the directive, or drop
{% standalone %} and let the layout above provide it
```

## Why this is a warning

A layout that declares `{% standalone %}` is the top of the chain for the pages under it, so nothing
above it emits anything any more. Without `{% assets %}` those pages arrive with no stylesheet and no
islands. Without `{% meta %}` they arrive with no title, no canonical and no hreflang.

It is a warning rather than an error because a page can legitimately want neither: a raw embed, a
plain-text answer, a document that carries its own inline style.

## How to fix it

Give the layout the head it now owns:

```gopage
{% standalone %}
<!doctype html>
<html lang="{{ locale.Tag }}">
<head>{% meta %}{% assets %}</head>
<body>{% outlet %}</body>
</html>
```

Or drop `{% standalone %}` and let the layout above keep providing the head.

## What this check does not cover

Ordinary layouts. A nested layout without a head is normal, because the one above it has the head.
