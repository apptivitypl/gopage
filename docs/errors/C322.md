# C322 — value interpolated into css

## Message

```
error[GOPAGE-C322]: a value is interpolated into a <style> body
help: the escaper writes html entities, which css does not read as text; set a custom property on
      an element and use var() in the stylesheet
```

or, for the attribute form:

```
error[GOPAGE-C322]: a value is interpolated into a style attribute
help: the escaper writes html entities, which css does not read as text; bind a class instead, or
      set a custom property the stylesheet reads with var()
```

## Why this is rejected

CSS is a third grammar, next to HTML and JavaScript, and the HTML escaper is not written for it.
`{`, `}`, `(`, `)`, `:`, `;` and `/` all pass through untouched, and every one of them is structural
in a stylesheet.

```gopage
<style>.hero { color: {{ Props.Theme }} }</style>
```

A theme of `red } * { background: url(https://evil.example/pixel) } .z {` closes the rule, opens a
universal selector, and makes every element on the page fetch a URL the attacker chose. From there
CSS alone is enough to read the page back out — attribute selectors such as
`input[value^="a"] { background: url(...) }` leak a value one character at a time — and enough to
cover the page with an element the visitor clicks by mistake.

The attribute form is the same grammar in a smaller space:

```gopage
<div style="width: {{ Props.Width }}">
```

`100px; background: url(https://evil.example/)` needs no quote and no angle bracket to work.

Escaping `<` keeps the payload from closing `</style>`, so this stays inside CSS rather than becoming
script. That bounds the damage; it does not remove it.

## How to fix it

Most dynamic styling is a choice between styles you already wrote, which is what `:class` is for:

```gopage
<div :class="{ 'is-wide': Props.Wide, 'is-narrow': !Props.Wide }">
```

When you genuinely need a value rather than a choice, pass it as a custom property and let the
stylesheet consume it. Custom properties are a value context, so the browser will not read structure
out of them:

```gopage
<div class="hero" style="--hero-color: var(--theme)"></div>
```

For a value that only the server knows, hand it to an island and let the island set the property on
the element with `style.setProperty`.
