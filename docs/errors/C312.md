# C312 — malformed submit handler

## Message

```
error[RILL-C312]: Submit has the wrong signature
help: write func Submit(ctx *rill.Ctx, params rill.Params, form MyForm) (rill.Action, error)
```

## Why this is rejected

The generated provider decodes the request body into the third parameter and calls `Submit`
directly, without reflection over the function itself. The compiler reads that parameter's type to
know what to decode into, so the shape is fixed.

## How to fix it

Match the signature exactly. The form type is whatever struct you name — its fields carry the
`validate` tags:

```go
type ContactForm struct {
	Email   string `validate:"required,email"`
	Consent bool   `validate:"accepted"`
}

func Submit(ctx *rill.Ctx, params rill.Params, form ContactForm) (rill.Action, error) {
	return rill.RedirectTo("/thanks").Flash("contact.sent"), nil
}
```

Returning a `nil` action with no error re-renders the page, so return a redirect on success —
a submission that answers with a document leaves the browser able to repost it.
