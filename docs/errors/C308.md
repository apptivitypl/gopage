# C308 — component argument mismatch

## Message

```
error[RILL-C308]: Badge needs the prop Label
```

## Why this is rejected

Component props are a typed contract. Passing an unknown attribute or omitting a required one would render a component in a state its template never expects.

## How to fix it

Pass the prop as `Name="literal"` or `:Name="expression"`. Booleans default to false, pointers default to nothing, and a field with `rill:"default=…"` uses that value. Everything else is required.
