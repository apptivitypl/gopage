# C104 — route handler without a method

## Message

```
error[GOPAGE-C104]: app/api/health/route.go declares no HTTP method
```

## Why this is rejected

A `route.go` file answers a URL. The function names are the contract: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS`. A file with none of them registers a route that can only ever reply 405, which is never what the author meant.

## How to fix it

Name a function after the method it answers, or delete the file if the segment serves a page instead.

```go
package route

import "github.com/apptivitypl/gopage"

func GET(ctx *gopage.Ctx, params gopage.Params) (gopage.Response, error) {
	return gopage.JSON(map[string]string{"status": "ok"}), nil
}
```
