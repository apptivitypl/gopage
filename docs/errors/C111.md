# C111 — link points at no route

## Message

```
error[RILL-C111]: no route answers /listing/9
```

## Why this is rejected

Internal links are matched against the route table at build time. A link that matches nothing is a 404 waiting to happen, and it is the kind of mistake that survives review because the markup looks right.

## How to fix it

Fix the path, add the route, or opt out with `href="!/…"` when the target lives outside rill — a legacy backend behind the migration proxy, for example. External links, `mailto:`, `tel:`, anchors and protocol-relative URLs are never checked.
