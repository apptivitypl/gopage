# C503 — private value in a cached fragment

## Message

```
error[GOPAGE-C503]: Session.Email is private and this fragment is cached
help: drop cache= from {% fragment "sidebar" %}, or move the private value outside it
```

## Why this is rejected

A cached fragment is keyed by the values its body reads, and its bytes are handed to whoever
produces the same key. A field marked private — a session, a basket, anything belonging to one
visitor — has no business in that key, so the first visitor's bytes would be served to the second.

This is the one class of cache bug that cannot be found by looking at a response: it is correct
for the visitor who filled the cache and wrong for everyone after them. The compiler refuses the
combination instead.

## The values that belong to one visitor

Privacy is declared with a tag, but three things are per-visitor by construction and need no tag.
They are rejected in a cached fragment on sight:

```
error[GOPAGE-C503]: <Form> carries a csrf token and this fragment is cached
help: the token belongs to one visitor; drop cache= from {% fragment "signup" %}, or keep the form
      outside the cached part
```

- **`<Form>`**, because it writes a hidden `__csrf` field. A cached form hands one visitor's token
  to everyone who sees the fragment for as long as it lives, which is the token being valid across
  users — and every other visitor's submission then fails the check against their own cookie.
- **`form.Token`**, the same value read directly.
- **`flash`**, which is a message addressed to the visitor who caused it and frequently carries
  their name or address.

A local that happens to share the name shadows the root and is not affected, so
`{% let flash = "welcome" %}` inside the fragment is fine.

Note the page cache already refuses any request carrying a flash. The fragment cache is a separate
store with its own key, which is why this is a compile-time rule rather than a runtime one.

## How to fix it

Mark the field and keep it out of cached regions:

```go
type Props struct {
	Listing Listing
	Viewer  Viewer `gopage:"private"`
}
```

Either drop `cache=` from the fragment, or move the private read outside it:

```gopage
<p>{{ Viewer.Email }}</p>

{% fragment "reviews" cache="5m" %}
    {% for r in Reviews %}<blockquote>{{ r.Body }}</blockquote>{% endfor %}
{% endfragment %}
```

The rule covers what is declared: a field is private when it carries the tag, and a path is private
when any segment on the way to it is. Inferring the mark from the body of `Load` is not done yet.
