# C306 — malformed component tag

## Message

```
error[RILL-C306]: <Card> is never closed
```

## Why this is rejected

A component tag that does not parse leaves the compiler guessing where the children end, and children are spliced into the component body verbatim.

## How to fix it

Close the tag with `>` and the element with `</Card>`, or use the self-closing form `<Card />`. Bound attributes need a quoted value: `:Label="expression"`. A named slot is written `<Template #footer>…</Template>`.
