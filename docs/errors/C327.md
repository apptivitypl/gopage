# C327 — boolean attribute bound to a value

## Message

```
error[GOPAGE-C327]: open is a boolean attribute, so a bound value would always emit it
help: write open?="condition" to leave it out when the condition is false
```

## Why this is rejected

HTML boolean attributes carry no value: `open`, `checked`, `disabled`, `selected`, `hidden` and their
kin are true when present and false when absent. `open="false"` opens the element.

So `:open="item.Open"` cannot mean what it looks like. Binding emits the attribute with the value
rendered into it, which the browser reads as present — every accordion open, every checkbox checked,
every button disabled.

## How to fix it

Use the conditional form, which leaves the attribute out when the condition is false:

```gopage
<details open?="item.Open">
	<summary>{{ item.Name }}</summary>
</details>

<input type="checkbox" checked?="filter.Active">
<button disabled?="!form.Ready">send</button>
```

## What this check does not cover

Attributes that carry a real value. `:value="item.Name"` and `:class="item.Style"` bind as before —
only the boolean list is refused.
