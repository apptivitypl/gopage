# C305 — unknown field in template

## Message

```
error[RILL-C305]: Props has no field Titel
```

## Why this is rejected

Template paths are checked against the props schema at build time. A typo caught here is a typo that never reaches a rendered page.

## How to fix it

Use one of the fields the message lists. Inside a loop the variable takes the element type, so `{% for c in Cards %}{{ c.Title }}{% endfor %}` is checked against the element struct, not against Props.
