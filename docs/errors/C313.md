# C313 — unknown filter

## Message

```
error[GOPAGE-C313]: no filter named uppercase
help: did you mean upper?
```

## Why this is rejected

Filters are a closed registry resolved at build time: the plan stores an index, and the interpreter
calls the function behind it with no lookup and no allocation. A name that is not in the registry
has no index to store.

The same code reports a filter called with the wrong number of arguments — `upper` takes none,
`money` takes one — because the plan holds exactly one optional argument slot per call.

## How to fix it

Use one of the registered filters:

| Filter | Argument | Example |
|---|---|---|
| `upper`, `lower`, `trim` | none | `{{ Name \| upper }}` |
| `default` | the replacement | `{{ Note \| default("none") }}` |
| `truncate` | a whole number | `{{ Body \| truncate(80) }}` |
| `number` | none | `{{ Views \| number }}` |
| `money` | a currency code | `{{ Price \| money("PLN") }}` |

Filters chain left to right: `{{ Note | default("none") | upper }}`. For anything the registry
does not cover, compute the value in `Load` or as a method on `Props`.
