# C113 — standalone outside a layout

## Message

```
error[GOPAGE-C113]: {% standalone %} outside a layout
help: only a layout can start its own chain; move the directive to the layout above this file
```

## Why this is rejected

`{% standalone %}` decides which layouts wrap a page. That decision belongs to a layout, because a
layout is what wrapping is made of. In a page or a component the directive has no effect at all, and
looks like it has one: the page still renders inside every layout above it.

## How to fix it

Put it in the layout that should be the top of the chain:

```
app/
  layout.gopage            the site chrome
  (auth)/
    layout.gopage          {% standalone %}, so nothing above it wraps these pages
    login/page.gopage
```

```gopage
{% standalone %}
<!doctype html>
<html lang="{{ locale.Tag }}">
<head>{% meta %}{% assets %}</head>
<body><main>{% outlet %}</main></body>
</html>
```

A page under `app/(auth)/login` then renders inside that layout alone. Everything outside the group
keeps the chrome.

## What this check does not cover

Whether the standalone layout is complete. A layout that starts its own chain answers for the head,
and [W705](W705.md) says so when `{% meta %}` or `{% assets %}` is missing.
