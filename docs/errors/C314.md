# C314 — malformed fragment

## Message

```
error[GOPAGE-C314]: cache="5 minutes" is not a duration
help: write a Go duration such as "5m" or "1h30m"
```

## Why this is rejected

A fragment is a named, separately cached region of a plan. The name is its cache key and the
durations are stored in the manifest as integers, so both are read at build time. The same code
reports two fragments sharing a name — the second would silently serve the first one's bytes — and
a template holding more fragments than the manifest reserves room for.

## How to fix it

```gopage
{% fragment "reviews" cache="5m" stale="1h" %}
    <h2>{{ t("reviews.count", count = len(Reviews)) }}</h2>
{% endfragment %}
```

`cache` is the time the bytes stay fresh; `stale` is how much longer they may be served while a
refresh runs behind the request. A fragment without `cache` is rendered every time and still marks
a region for differential navigation.
