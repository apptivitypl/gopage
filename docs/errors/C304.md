# C304 — unknown struct in props

## Message

```
error[GOPAGE-C304]: Props.Card refers to Crad, which is not declared here
```

## Why this is rejected

A props field can only point at a struct the compiler can see, because it has to generate an accessor for it.

## How to fix it

Declare the struct in the same block, or convert the value in `Load`. The compiler suggests the closest declared name when there is one.
