# C201 — malformed expression

## Message

```
error[RILL-C201]: expected a value, found unexpected input
```

## Why this is rejected

The expression grammar is closed on purpose. Every restriction buys a static analysis, so the compiler refuses input it cannot place rather than inventing a meaning for it.

## How to fix it

Expressions read props fields, locals, string and number literals, and the operators `|| && == != < <= > >= ~ + - * / % !`. Anything the grammar cannot express belongs in `Load`, in a method on `Props`, or in a filter. The loop form is `{% for item in items %}` and the binding form is `{% let name = expression %}`.
