# C602 — plural form mismatch

## Message

```
error[RILL-C602]: reviews.count declares plural forms in pl but is called without a count
help: pass the count: t("reviews.count", count = len(Reviews))
```

## Why this is rejected

A message either has one form or several. The call site and the catalog have to agree: a message
with `one`, `few` and `many` needs a number to pick between them, and a message with a single form
has nothing to pick.

Getting this wrong is invisible in the default locale and wrong in every other one — English hides
it because two forms are enough, Polish does not.

## How to fix it

Pass the count when the catalog declares forms:

```rill
{{ t("reviews.count", count = len(Reviews)) }}
```

```toml
[reviews]
count = { one = "{count} opinia", few = "{count} opinie", many = "{count} opinii" }
```

`{count}` in the text is replaced with the number. Drop the argument when the message has a single
form, or give the message forms when it needs them.
