# C006 — unbalanced block directive

## Message

```
error[GOPAGE-C006]: {% if %} is never closed
```

## Why this is rejected

Block directives nest, so an unclosed one swallows everything after it. Rather than guessing where you meant the block to end, the compiler reports the opening directive that has no partner.

## How to fix it

Close the block with its matching directive: `{% endif %}` for `{% if %}`, `{% endfor %}` for `{% for %}`. A closing directive on its own, with nothing open, is reported the same way.
