# C307 — unknown component

## Message

```
error[RILL-C307]: no component named Badeg
```

## Why this is rejected

Components are resolved at build time from `components/<Name>/template.rill`. There is no runtime lookup, so an unresolved name cannot become a silent blank.

## How to fix it

Check the spelling against the list in the message, or create `components/<Name>/template.rill`. Components cannot render themselves: a component body is inlined into its caller, so recursion has no base case.
